# Прецеденты системы «Список дел»

## Прецедент «Добавить дело»
- Цель: зафиксировать новое дело в списке.
- Основной сценарий: пользователь выбирает пункт меню 1, вводит название и срок.
- Альтернативный сценарий: название пустое — программа выводит сообщение об ошибке и повторяет ввод.
- Связи: <<include>> «Сохранить данные».

## Прецедент «Просмотреть список дел»
- Цель: увидеть все текущие дела и их статусы.
- Основной сценарий: пользователь выбирает пункт меню 2, программа выводит список дел.
- Альтернативный сценарий: список пуст — выводится сообщение «Список дел пуст».

## Прецедент «Отметить дело выполненным»
- Цель: изменить статус дела на «выполнено».
- Основной сценарий: пользователь выбирает пункт меню 3 и указывает дело, программа ставит флаг done.
- Альтернативный сценарий: дело не найдено — сообщение об ошибке, возврат в меню.
- Связи: <<include>> «Сохранить данные», <<extend>> «Просмотреть список дел».

## Прецедент «Удалить дело»
- Цель: убрать дело из списка.
- Основной сценарий: пользователь выбирает пункт меню 4, указывает дело, программа удаляет его.
- Альтернативный сценарий: дело не найдено — сообщение об ошибке.
- Связи: <<include>> «Сохранить данные».

## Прецедент «Сохранить данные» (служебный)
- Цель: сохранить текущее состояние списка в файл.
- Основной сценарий: вызывается автоматически после каждого изменения.
- Альтернативный сценарий: ошибка записи файла — выводится предупреждение.
