# Архитектура: Список дел (To-Do List)

## Компоненты

- **main.py** — точка входа: инициализирует приложение и запускает цикл меню.
- **ui.py** — слой представления: печатает меню, читает ввод пользователя, выводит список дел.
- **logic.py** — бизнес-логика: класс Task (модель дела) и TaskManager (добавление, отметка выполнения, удаление).
- **storage.py** — слой хранения: чтение и запись списка дел в файл tasks.txt.

## Связи

- main.py запускает ui.py.
- ui.py обращается к logic.py (через TaskManager).
- logic.py читает и сохраняет данные через storage.py.

## Правило зависимостей

Зависимость идёт только вниз: main → ui → logic → storage.
Обратные вызовы запрещены: storage.py не знает о ui.py и logic.py.
